# Security Policy

## Reporting a vulnerability

Please do not open a public issue containing credentials, pairing codes, device identifiers, or a reproducible exploit against someone else's device. Use GitHub's private vulnerability reporting feature if enabled for this repository, or contact the repository maintainer privately.

## Safe use

- Only pair devices you own or are authorized to administer.
- Use a trusted local network.
- Treat QR images and pairing codes as temporary credentials.
- Disable Android Wireless debugging when finished.
- Never commit generated QR images or pairing secrets.
